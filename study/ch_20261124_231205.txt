Aider 运行方式（已有源码项目）
环境：Python >=3.10,<3.15；Docker 可选
工作目录：C:\Code\AI\aider_study

[首次配置]
CLI 依赖：已完成，无需重复安装
Web 依赖：python -m pip install -e ".[browser]"
配置：.env 已设置 OPENAI_BASE_URL、OPENAI_API_BASE、AIDER_MODEL
说明：OPENAI_API_KEY=${OPENAI_API_KEY} 从 Windows 用户环境变量继承
依据：pyproject.toml:20-35；aider/main.py:362-388

[CLI]
启动：python -m aider
入口：aider.main:main
访问：当前终端
依据：aider/__main__.py:1-3；pyproject.toml:26-27

[Web]
启动：python -m aider --gui
入口：aider.main:main -> launch_gui -> aider/gui.py
访问：http://localhost:8501（推断，终端显示的 URL 为准）
依赖：使用首次配置中的 browser 安装，CLI 和 Web 不重复安装
依据：aider/args.py:657-661；aider/main.py:234-269

[Docker CLI]
首次构建：docker build -f docker/Dockerfile -t aider .
每次启动：docker run --rm -it -e OPENAI_API_KEY -v "${PWD}:/app" aider
访问：当前终端
依据：docker/Dockerfile:59-80

[Docker Web]
首次构建：docker build --target aider-full -f docker/Dockerfile -t aider-full .
每次启动（推断）：docker run --rm -it -e OPENAI_API_KEY -p 8501:8501 -e STREAMLIT_SERVER_ADDRESS=0.0.0.0 -v "${PWD}:/app" aider-full --gui
端口：8501（推断）
依据：docker/Dockerfile:35-56；aider/args.py:657-661

[备注]
- docker build 只执行一次；每次启动 Docker 版都执行 docker run。
- .env 当前引用 Windows 用户环境变量，Docker 使用 -e OPENAI_API_KEY 传入。
- 不要暂存或提交 .env；当前变量引用方式不适用 docker --env-file。
